# Contributing

Thanks for taking a look. This is a small, dependency-free portfolio project.

## Getting started

- Open `index.html` in a modern browser or serve the folder with `python -m http.server 8000`.
- Keep the project runnable without a package manager or external service.
- Keep sample data clearly identified and do not add real credentials or private customer data.

## Changes

- Keep markup semantic and controls keyboard-operable.
- Explain any data assumptions and user-facing limitations.
- Prefer small, focused changes that preserve the project’s visual system.
- For visual changes, include a concise before/after description in a pull request.

## Reporting an issue

Include your browser, steps to reproduce, expected behavior and actual behavior. Remove private information from examples.
